# Fundamental Data  Stacks and Queues

## Description
This project demonstrates the implementation of stacks and queues using both arrays and linked lists.

The program includes:

- ArrayStack
- LinkedStack
- ArrayQueue
- LinkedQueue
- Balanced Parentheses Checker
- Print Queue Simulation

## Files

| File | Description |
|--------|-------------|
| node.py | Node class used by linked structures |
| array_stack.py | Array-based stack implementation |
| linked_stack.py | Linked-list stack implementation |
| array_queue.py | Circular array queue implementation |
| linked_queue.py | Linked-list queue implementation |
| applications.py | Application exercises |
| main.py | Menu-driven test program |
| analysis.md | Written analysis answers |

## Features

### Stack Operations
- Push
- Pop
- Peek
- Is Empty
- Is Full

### Queue Operations
- Enqueue
- Dequeue
- Peek Front
- Is Empty
- Is Full
